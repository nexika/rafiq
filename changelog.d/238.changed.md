The phone page now listens on a socket only you can open, `~/.config/rafiq/run/mobile.sock`, so another account on this computer can't take its place while Rafiq is stopped and collect your phone's token. Point Tailscale at it once with `tailscale serve --bg unix:<path>` (`rafiq mobile pair` prints it). If you set Tailscale up before, move it with `tailscale serve --https=443 off` first: `rafiq run` won't start while Tailscale still sends the phone to the old port. `[mobile] listen = "port"` keeps the port for a Tailscale that can't serve a socket, a phone page that can't start stops `rafiq run` with the reason, and `rafiq doctor` checks where Tailscale sends the phone.
