On a Mac shared by several accounts, another account's program can no longer use Rafiq's panel: `rafiq ask`, `rafiq panel`, `rafiq mcp`, the gesture tracker and the widget reach Rafiq over a socket in `~/.config/rafiq/run` that only you can open, the panel refuses another account's program there, and on macOS the panel's port takes no token at all, only the browser's one-time key. They never send the token to a socket that isn't yours.
